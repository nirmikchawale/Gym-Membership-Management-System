# Active UI Placeholder Scan Policy

For the completed Gridstone scope, active frontend code must not present approved features as unfinished.

Forbidden in active non-payment UI copy:

- `Not implemented`
- `Not implemented yet`
- `Coming soon`
- `Later approved slice`
- `Planned capability`
- `Read-only demo`
- `Read-only preview`
- `State-changing controls are disabled`
- `does not mutate`

The sole allowed unavailable feature is **Payments**, and its dedicated page must explicitly state that the omission is intentional and approved rather than accidental or incomplete.

Historical planning documents may retain past language when clearly archival, but the live frontend must not use it for Members, Plans, Memberships, Attendance, Overview or Reports.
